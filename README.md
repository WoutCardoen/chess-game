# Chess Game

A two-player chess game in the terminal, written in Python.

## Features

- All standard moves, including castling, en passant and pawn promotion
- Only legal moves are allowed; check, checkmate and stalemate are detected
- The board flips each turn, and the legal moves of a selected piece are shown

## How to play

Enter the square of the piece to move (e.g. `e2`), then its destination (e.g. `e4`).
To castle, move the king two squares; the rook follows automatically.

## Run it

```
python chess_game.py
```

No external packages needed.
